# Wonda Luxe

Static storefront (HTML/CSS/JS) – orders are sent via WhatsApp.

## Host on GitHub Pages
1. Create a new repo and upload the **contents** of this folder (so `index.html` is at the repo root).
2. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save.
3. Your site appears at `https://<username>.github.io/<repo>/` after a minute.

## Editing products
Edit `assets/js/products.js` (name, price, image, description, ingredients). Add photos to `assets/images/`.
